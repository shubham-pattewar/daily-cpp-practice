# Daily C++ Practice

180-day C++ / DSA practice repository.

- `curriculum/Day-001` ... `Day-180`: prepared C++17 solutions.
- `daily/`: days published by GitHub Actions.
- `.github/workflows/daily-cpp.yml`: publishes the next day automatically at 10:15 PM IST.

Every published day contains:
- `problem.md`
- `solution.cpp`
- `explanation.md`
- `tests.txt`

The workflow compiles each solution with C++17 before committing it.
